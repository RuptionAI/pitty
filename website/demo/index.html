Watch Pitty work.

A real session with Pitty 0.8.0 and a free cloud model, recorded in a terminal. Nothing is staged: the model chose every action you see. Waits for the model are sped up, and the video marks each one.

What happens in the video

  1. Asked to add a --name option and run the program, the model proposes an edit. Pitty shows the exact old text and its replacement, and nothing is written until Y. The command waits the same way.
  2. With /web duckduckgo, Pitty searches DuckDuckGo itself, with no key. Every search and page fetch waits for a yes, and the answer lists the sources it used.
  3. Shift+Tab switches to Auto. The model adds a test and runs it without stopping, and every action is still recorded.
  4. /audit checks the decision log: each line holds the SHA-256 of the line before it, so an edited or deleted line breaks the chain.
