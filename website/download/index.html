Install Pitty.

Paste one block into your terminal. It downloads Pitty, checks the download, installs it, and opens it. The first change a model asks for waits for your Y.

  1. Choose your computerA Mac, or 64-bit Intel or AMD Linux.
  2. Copy its blockThe Copy button takes the whole thing.
  3. Paste it into TerminalPress Return. Pitty opens when it finishes.

On a Mac

One block covers both Apple silicon and Intel Macs on macOS 11 or later. To open Terminal, press ⌘ + Space, type Terminal, and press Return.

This release is not signed with an Apple Developer ID or notarized; that is the next Mac build. The installer downloads with curl, which macOS does not quarantine. If macOS blocks a download from your browser

Terminal on macOS
(
  set -eu
  pitty_cwd=$PWD
  case "$(uname -sm)" in
    "Darwin arm64") pitty_target=aarch64-apple-darwin ;;
    "Darwin x86_64") pitty_target=x86_64-apple-darwin ;;
    *) printf 'Use this command on a Mac.\n' >&2; exit 1 ;;
  esac
  pitty_pkg="pitty-0.8.0-$pitty_target"
  pitty_tmp=$(mktemp -d "${TMPDIR:-/tmp}/pitty-install.XXXXXX")
  trap 'rm -rf "$pitty_tmp"' EXIT
  cd "$pitty_tmp"
  curl -fLsS --retry 2 --proto '=https' -O "https://pitty.tech/downloads/$pitty_pkg.tar.gz?v=70e1c0d5"
  curl -fLsS --retry 2 --proto '=https' -O "https://pitty.tech/downloads/$pitty_pkg.tar.gz.sha256?v=70e1c0d5"
  shasum -a 256 -c "$pitty_pkg.tar.gz.sha256"
  tar -xzf "$pitty_pkg.tar.gz"
  "$pitty_pkg/pitty" --version
  mkdir -p "$HOME/.local/bin"
  install -m 755 "$pitty_pkg/pitty" "$HOME/.local/bin/pitty"
  cd "$pitty_cwd"
  "$HOME/.local/bin/pitty"
)

Installs to ~/.local/bin/pitty. No administrator password or Rust toolchain needed. Run it again to update.

On Linux

For 64-bit Intel or AMD Linux with glibc 2.35 or later, which includes Ubuntu 22.04 and newer. It needs curl, tar, and sha256sum.

Linux on ARM is not in this release. Windows users can try this build inside x64 WSL2; that path is untested.

Terminal on Linux
(
  set -eu
  pitty_cwd=$PWD
  case "$(uname -sm)" in
    "Linux x86_64") pitty_target=x86_64-unknown-linux-gnu ;;
    *) printf 'Use this command on 64-bit Intel/AMD Linux.\n' >&2; exit 1 ;;
  esac
  pitty_pkg="pitty-0.8.0-$pitty_target"
  pitty_tmp=$(mktemp -d "${TMPDIR:-/tmp}/pitty-install.XXXXXX")
  trap 'rm -rf "$pitty_tmp"' EXIT
  cd "$pitty_tmp"
  curl -fLsS --retry 2 --proto '=https' -O "https://pitty.tech/downloads/$pitty_pkg.tar.gz?v=70e1c0d5"
  curl -fLsS --retry 2 --proto '=https' -O "https://pitty.tech/downloads/$pitty_pkg.tar.gz.sha256?v=70e1c0d5"
  sha256sum -c "$pitty_pkg.tar.gz.sha256"
  tar -xzf "$pitty_pkg.tar.gz"
  "$pitty_pkg/pitty" --version
  mkdir -p "$HOME/.local/bin"
  install -m 755 "$pitty_pkg/pitty" "$HOME/.local/bin/pitty"
  cd "$pitty_cwd"
  "$HOME/.local/bin/pitty"
)

The checksum must pass before anything is unpacked, and the new Pitty must run before it replaces an installed one.

When Pitty opens

  1. Type /key and paste your OpenRouter API key into the masked field. OpenRouter is the default.
  2. Prefer another provider? Type /interface openai, or /interface compatible with a base URL, then /model and a model id. A compatible endpoint can run without a key.
  3. Or use a model on this computer: start Ollama or the local server in LM Studio, then type /local and choose a model. No key is needed.
  4. On OpenRouter, type /models free and pick a model. /help lists every command.

Model requests use the account behind that interface and may cost money. PDF reading belongs to OpenRouter; web search works with any model once you type /web on. Your own /run commands and MCP mode need no chat key.
