Start a conversation.

Pitty opens on OpenRouter. Enter /key and paste your OpenRouter API key into the masked field; it is saved on your computer with owner-only permissions. Then choose a model:

Inside Pitty
/models free

OpenAI and another chat endpoint use the same review. Name the model. PDF parsing stays on OpenRouter. A compatible endpoint can run with no key.

/interface compatible http://127.0.0.1:11434/v1

Use a model on this computer

Start a local model server, such as Ollama or the local server in LM Studio, then type /local. Pitty finds Ollama, LM Studio, llama.cpp, vLLM, Jan, GPT4All, and Docker Model Runner on their usual ports, honors OLLAMA_HOST, and lists every model they serve. Choose one and chat stays on your machine, with no key. From the terminal, pitty --local does the same. A model needs function calling to use the file tools; for a chat-only model, type /tools off.

Send a message. /help lists every command, and typing / opens the command menu. Local tools need a model that supports function calling; use /tools off for a chat-only model.

Choose a working folder

Terminal (replace the project path)
"$HOME/.local/bin/pitty" --directory /path/to/project

The header shows the working folder. /pwd prints its full path and any connected folders.

Files. Commands. Results.

Ask Pitty to inspect a file, make a change, and run a test. To run a command yourself, start it with /run or /exec:

Inside Pitty

/run cargo test

/actions

/tools ask, the default
Preview file changes, commands, web requests, and sensitive reads. Y approves once; A approves it, along with any other review waiting, and switches to Auto; N, Enter, or Esc declines. Ordinary reads and searches of your files run without individual approval. A long task checks in every 16 model turns, and you choose whether it continues.
/tools auto
Run model-requested tools without individual review, including work already running, and let long tasks continue until they finish or reach the turn limit: 100 model turns per request unless you change it with /turns. Every action is still recorded in /actions and the decision log. Shift + Tab switches between Ask and Auto at any time.
/tools off
Turn off model-requested tools. Chat and your own commands still work.

Your /run commands execute exactly what you typed. Commands have your account’s filesystem and network permissions, including access outside connected folders. They use noninteractive input, a timeout, and bounded output. A model-requested shell starts from a cleared environment, so API-key variables, including OPENROUTER_API_KEY, OPENAI_API_KEY, and PITTY_API_KEY, are not inherited.

Pitty checks a write against the file it showed you. If the file changed after approval, the write does not land and Pitty reports File changed after approval; prepare the edit again. A credential-like path, such as .env or an SSH key, needs its own approval before a read, and the review says the contents will be sent to the model. Search skips those files. Over MCP, a credential read is declined in either mode.

Ctrl + C stops active work; completed file changes stay. /actions lists what ran and its output. /audit checks the decision log: each approval, decline, and run is one line that stores the SHA-256 of the line before it, so an edited or deleted line breaks the chain. The log keeps decisions, never file contents or command output. When nothing is running, Ctrl+C clears the draft, and a second Ctrl+C asks before closing. /retry will not repeat a turn that already performed local actions.

Bring the work with you.

Inside Pitty (replace the example paths)

/connect ~/Projects/example

/files

/attach ./diagram.png

/attachments

Browse connected local or mounted network folders, or drag file paths into the composer. Review staged files before sending. /detach 1 removes one staged file; /detach all clears the list. Images, PDFs, audio, video, and UTF-8 text depend on the selected model and provider; unsupported files are named. OpenRouter can parse a PDF in the request. Other chat interfaces send the conversation without that parser.

Connecting a folder does not upload it. Enabled model tools may read its files as part of your task, and those results are sent to the model.

Give tasks their own space

Inside Pitty

/agent planner Outline the changes

/agent reviewer Check the implementation

/agents

Up to four model requests run at once, including the main chat. Tasks inherit the conversation, attachments, and tool policy. Use /agent open 1 to continue from a finished result; handoffs are manual.

Search the web with any model

Inside Pitty

/web on

/web duckduckgo

/web searxng http://127.0.0.1:8888

/web off

Web search works with every model, local ones included. Pitty searches DuckDuckGo, which needs no key, or your own SearXNG instance, Brave Search (BRAVE_SEARCH_API_KEY), or Tavily (TAVILY_API_KEY), keys it reads from your environment or ~/.config/pitty/.env. The model can search, read the pages it picks, and cite them; the sources are listed under the answer. In Ask mode, each search and page fetch shows for review first, because a query or address can carry anything the model has read. Pitty never fetches private or local network addresses. On OpenRouter, /web on uses OpenRouter’s hosted search unless you choose a provider. With /tools off, Pitty searches your message before sending it and hands the results to the model.

The footer shows whether search is on. It is off at startup, and paid providers can add charges. This switch does not limit a shell command’s network access.

Your account & your history.

Model chat uses the key for the interface you chose. On OpenRouter, inference, web search, and parallel tasks may incur charges, so set a spending limit on the key. OpenAI and another endpoint bill on their own terms. A compatible endpoint can run with no key. A tool-assisted turn can make up to 16 model requests, and the token cap applies to each one.

Conversations, attachments, and tool results are saved locally in plaintext by default. To keep a session in memory only:

Terminal
"$HOME/.local/bin/pitty" --no-history

Sent conversations, files, and tool results go to the chat endpoint you chose, whose retention policies vary. Turning off local history does not change provider retention.

Installation help.

macOS security prompts

This release is not signed with an Apple Developer ID and is not notarized. The copy-and-paste installer downloads with curl, which macOS does not quarantine. If macOS blocks a copy you downloaded in a browser, follow Apple’s instructions for opening apps safely. Pitty never changes Gatekeeper settings. A notarized Mac install is the next Mac build.

Installing a downloaded archive

Download your archive and its checksum, open a terminal in the download folder, and run the commands for your computer. Nothing is extracted unless the checksum reports OK.

Mac with Apple silicon: run in the download folder
shasum -a 256 -c pitty-0.8.0-aarch64-apple-darwin.tar.gz.sha256 &&
tar -xzf pitty-0.8.0-aarch64-apple-darwin.tar.gz &&
mkdir -p "$HOME/.local/bin" &&
install -m 755 pitty-0.8.0-aarch64-apple-darwin/pitty "$HOME/.local/bin/pitty" &&
"$HOME/.local/bin/pitty" --version

Mac with Intel: run in the download folder
shasum -a 256 -c pitty-0.8.0-x86_64-apple-darwin.tar.gz.sha256 &&
tar -xzf pitty-0.8.0-x86_64-apple-darwin.tar.gz &&
mkdir -p "$HOME/.local/bin" &&
install -m 755 pitty-0.8.0-x86_64-apple-darwin/pitty "$HOME/.local/bin/pitty" &&
"$HOME/.local/bin/pitty" --version

Linux on x64: run in the download folder
sha256sum -c pitty-0.8.0-x86_64-unknown-linux-gnu.tar.gz.sha256 &&
tar -xzf pitty-0.8.0-x86_64-unknown-linux-gnu.tar.gz &&
mkdir -p "$HOME/.local/bin" &&
install -m 755 pitty-0.8.0-x86_64-unknown-linux-gnu/pitty "$HOME/.local/bin/pitty" &&
"$HOME/.local/bin/pitty" --version

The copy-and-paste installer does all of this in one step.

“Command not found”

Start Pitty by its full path:

Terminal
"$HOME/.local/bin/pitty"

To make pitty work in new terminals, add ~/.local/bin to your PATH. For zsh, the macOS default:

Terminal (zsh)
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc

For bash, use ~/.bashrc instead of ~/.zshrc. Open a new terminal afterwards.

Updates & removal

Run the current installation block again to update. Deleting ~/.local/bin/pitty removes the program; your key, preferences, and history stay. /status shows where history is stored.
